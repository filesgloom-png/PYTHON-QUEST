# PYTHON QUEST

Нативное Android-приложение для изучения Python с нуля на русском языке.

## Технологии
- Kotlin и Android SDK
- Chaquopy с встроенным Python 3.11
- GitHub Actions для проверки и сборки APK
- Прогресс уроков и XP сохраняются локально на устройстве

## Первый набор уроков
1. Первая программа: `print()`
2. Переменные
3. Арифметические операции
4. Условия `if`
5. Цикл `for`

В приложении есть редактор, запуск настоящего Python-кода, вывод ошибок, подсказки, проверка упражнений, XP и уровни.

## Сборка APK
Каждый push в `main` запускает GitHub Actions. После успешной сборки debug APK загружается как артефакт workflow. Открой Actions, выбери успешный запуск и скачай `PYTHON-QUEST-debug-apk`.

## Технологии сборки
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- JDK 17
- Chaquopy 16.0.0 / Python 3.11

Это ранняя учебная версия. Выполнение пользовательского кода не является защищённой песочницей: запускай только код, который понимаешь или которому доверяешь.
