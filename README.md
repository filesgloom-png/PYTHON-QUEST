# PYTHON QUEST

Мобильное PWA-приложение для изучения Python с нуля на русском языке.

## Возможности MVP
- 5 стартовых уроков: `print()`, переменные, арифметика, `if`, `for`.
- Запуск настоящего Python-кода в браузере через Pyodide.
- Проверка заданий, подсказки и вывод ошибок.
- XP, уровни, отметки пройденных уроков и серия занятий.
- Сохранение прогресса в локальном хранилище устройства.
- Установка на главный экран Android через поддерживающий браузер.
- GitHub Actions для базовой проверки проекта и публикации GitHub Pages.

## Запуск
Открой опубликованную GitHub Pages-страницу в браузере Android. Для запуска Python нужен интернет, чтобы загрузить Pyodide при первом старте. Прогресс хранится локально в браузере.

## Публикация
В репозитории открой **Settings → Pages** и выбери **GitHub Actions** как источник публикации. Workflow проекта соберёт и опубликует сайт после успешных проверок.

## Технологии
HTML, CSS, JavaScript, Pyodide, PWA, GitHub Actions.

## Важно
Это учебная версия. Код выполняется в браузерном окружении Pyodide, а не в отдельном системном Python на Android. Не запускай в редакторе неизвестный код, которому не доверяешь.
